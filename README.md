# חנות אפליקציות מבוזרת ומאובטחת (Decentralized App Store)

פרויקט גמר הנדסי המציג ארכיטקטורה היברידית מתקדמת עבור חנות אפליקציות חסינת צנזורה ומבוזרת לחלוטין. הפרויקט משלב טכנולוגיית בלוקצ'יין (Ethereum Smart Contracts) לניהול זהויות, גרסאות ומטא-דאטה, יחד עם רשת שיתוף קבצים מבוזרת (P2P BitTorrent) להפצה וטעינה של קבצי המקור, ושרת מטמון מהיר ואינדקס (Next.js + Prisma + PostgreSQL) לחוויית משתמש מודרנית וחלקה.

---

## 🏗️ ארכיטקטורת המערכת

המערכת מחולקת לשלושה רכיבים עיקריים:
1. **`contracts` (EVM Blockchain):** חוזים חכמים ב-Solidity הרצים על גבי רשת Hardhat מקומית. אחראיים על ה-Single Source of Truth של האפליקציות, היסטוריית הגרסאות, ועוגנים קריפטוגרפיים לאימות הנתונים.
2. **`web-ui` (Index & Cache Server):** אפליקציית Next.js 15 המבוססת על Prisma ו-PostgreSQL. ה-Backend מריץ תהליך רקע (Blockchain Listener) המאזין ל-Events בבלוקצ'יין ומסנכרן אותם למסד הנתונים המקומי. רכיב זה מנהל גם את מנגנוני ה-Aggregation (אגרגציה Off-chain) עבור ביקורות ודיווחים חתומים קריפטוגרפית כדי לחסוך עמלות גז (Gas Fees) למשתמשים.
3. **`desktop-client` (Native P2P Handler):** שרת לקוח מקומי המבוסס על Node.js ו-WebTorrent. הוא אחראי על הפיכת קבצי האפליקציות לטורנטים, הפצתם (Seeding), הורדתם דרך רשת העמיתים, וביצוע **אימות קריפטוגרפי קשוח (SHA-256 Hash Verification)** מול הנתונים שננעלו בבלוקצ'יין כדי להבטיח מניעת וירוסים והשחתת קבצים.

---

## 🛠️ דרישות קדם (Prerequisites)

לפני הרצת הפרויקט, ודא שהכלים הבאים מותקנים במחשבך:
* **Node.js** (גרסה 18 ומעלה)
* **PostgreSQL** (רץ וזמין, עם בסיס נתונים קיים עבור הפרויקט)
* **MetaMask Extension** בדפדפן (מוגדר לעבודה מול רשת מקומית `http://127.0.0.1:8545`)

### הגדרת קובץ הסביבה (.env)

לפני כל שלב אחר, יש ליצור קובץ בשם `.env` **בתיקיית השורש של הפרויקט** (לא בתוך `web-ui`, ולא בשם `.env.local`) המכיל לפחות את המשתנה הבא:


DATABASE_URL="postgresql://<user>:<password>@localhost:5432/<database_name>"

## 🚀 הוראות הפעלה (שלב אחר שלב)

כדי להפעיל את הפרויקט בצורה נכונה ולוודא סנכרון מלא בין רכיבי הבלוקצ'יין, ה-Database והשרת, יש לבצע את השלבים הבאים לפי הסדר המדויק, באמצעות טרמינלים נפרדים:

### שלב 1: הפעלת צומת בלוקצ'יין מקומי (Hardhat Node)
פתח טרמינל חדש, נווט לתיקיית החוזים והפעל את רשת הבדיקות המקומית. פקודה זו תדמה את רשת האתריום ותספק 20 ארנקים וירטואליים לצורך בדיקות:

```bash
cd contracts
npx hardhat node
```

השאר טרמינל זה פתוח לאורך כל העבודה.

### שלב 2: קימפול ופריסת החוזה החכם (Smart Contract Deployment)
פתח טרמינל שני, ופרוס את החוזה החכם אל רשת ה-Localhost שהרמת בשלב הקודם. תהליך זה מקמפל את קוד ה-Solidity, מעלה אותו, ומעדכן אוטומטית את קובצי ה-ABI וכתובת החוזה בתוך אפליקציית ה-Web:

```bash
cd contracts
npx hardhat run scripts/deploy.ts --network localhost
```

### שלב 3: הפעלת המערכת המלאה במצב Production מהיר (`prod`)
פתח טרמינל שלישי בתיקייה הראשית של הפרויקט (Root), והרץ את סקריפט האתחול המרכזי עם הדגל `prod`. סקריפט זה בונה ומריץ את שרת ה-Next.js ואת שרת ה-Desktop Client במצב Production המאפשר אופטימיזציה מלאה, טעינה מהירה של ה-UI וביצועים גבוהים:

```bash
./run.sh prod
```

כעת האפליקציה זמינה בדפדפן בכתובת: `http://localhost:3000`

## 🧪 הרצת בדיקות אוטומטיות (Automated Tests)

הפרויקט כולל מערך בדיקות הרמטי המוכיח את תקינות הלוגיקה והארכיטקטורה המבוזרת ללא צורך בממשק ויזואלי.

### 1. בדיקות החוזה החכם (Unit Tests)
בודק את לוגיקת הבלוקצ'יין ב-Solidity, אבטחת פונקציות, הרשאות אגרגציה, ומנגנוני דיווח וגרסאות:

```bash
cd contracts
npx hardhat test test/DappStore.ts
```

### 2. בדיקות רשת P2P ואימות קריפטוגרפי (Integrations & Mutation Tests)
מריץ בדיקות באמצעות Jest המוכיחות שרשת ה-P2P יוצרת ומורידה קבצים בצורה תקינה. הסוויטה כוללת טסט מיוטציה קריטי (Mutation/Corruption Test) הלוקח קובץ תקין, משנה בו בכוונה ביט בודד (מדמה האקר ברשת), ומוכיח שמנגנון ה-SHA-256 של הלקוח מזהה את השינוי, חוסם את הקובץ וזורק שגיאה מאובטחת:

```bash
cd desktop-client
npm test
```

## ✨ תכונות מרכזיות שהוטמעו במוצר

* **העלאה וזריעה מבוזרת:** העלאת קבצים חותמת עליהם קריפטוגרפית והופכת אותם לקישורי מגנט ברשת BitTorrent.
* **אימות תוכן הרמטי:** מניעת וירוסים מוחלטת ע"י הצלבת ה-Hash של הקובץ שירד מול ה-Hash המקורי שננעל בצורה בלתי-ניתנת לשינוי (Immutable) בבלוקצ'יין.
* **מנגנון אגרגציה חסכוני (Off-chain Aggregation):** שליחת ביקורות ודיווחים בחינם ע"י חתימה דיגיטלית ב-MetaMask (ללא עמלות גז למשתמש קצה). שרת ה-Indexer מאגד אותם באצוות (Batches) ומעגן אותם קריפטוגרפית בבלוקצ'יין אחת לכמה פעולות.
* **ניהול גרסאות והערות שדרוג:** תמיכה מלאה בהעלאת עדכונים לאפליקציות קיימות, יחד עם תיעוד "מה חדש בגרסה" (Release Notes) השמור ב-DB המקומי.
* **פרופילי משתמשים וניהול היסטוריה:** עמוד אישי לכל ארנק המציג את האפליקציות שהועלו, גרסאות בניהולו וסטטיסטיקות אישיות.
* **אבטחה מובנית מול MetaMask:** אימות חתימות דיגיטליות (Signature Verification) בצד השרת כדי למנוע זיופי זהויות או התחזות לארנקים אחרים בבקשות API.
